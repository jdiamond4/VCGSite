# Virginia Consulting Group

A simple redesign of the [Virginia Consulting Group website](http://vcguva.com/), made by Justin Diamond.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Static output lands in `dist/`. Deploy that folder to GitHub Pages (custom domain `vcguva.com`).

## Notes

- Hero includes an infinite **member placements** logo ticker.
- Apply CTA currently points to the existing Google Form.
- Additional pages (Team, Clients, Membership) can be added on this router.
